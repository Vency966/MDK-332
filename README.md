# МДК 01.02 — Задания по программированию

## 📁 Проекты

### 1. Зоопарк (Java)
Папка: `src/main/java/`
Система учёта животных в зоопарке:
- Абстрактный класс `Animal` + наследники (`Lion`, `Python`, `Wolf`, `Panther`, `Penguin`, `Viper`)
- Класс `Zoo` — добавление, удаление, подсчёт расходов
- Класс `Main` — 3 теста с `Assert`

### 2. HotelBooking (C++)
Папка: `HotelBooking/`
Система бронирования номеров в отеле (100 номеров):
- Класс `Room` — тип, цена, этаж
- Класс `Booking` — гость, даты, статус
- Класс `Hotel` — управление номерами и бронями
- Класс `BookingGenerator` — утилита для генерации тестовых броней
- `DateUtils` — работа с датами через `<ctime>`

**Функционал:**
1. Просмотр свободных номеров на даты
2. Бронирование
3. Отмена брони
4. Заезд / выезд
5. Просмотр всех броней
6. Расчёт стоимости
7. Генерация тестовых броней

## 🛠 Технологии
- Java 17, Maven
- C++ (стандарт C++11), компилятор MinGW
